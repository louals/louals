## About Me

I am a Software Engineer and Full-Stack Web Developer dedicated to engineering resilient, high-performance software systems. 

My technical range covers the complete development lifecycle—from constructing fluid frontend interfaces to designing decoupled microservices, optimizing database systems, and configuring automated deployment pipelines.

### Engineering Focus

* **Clean Code**: Writing maintainable, self-documenting, and testable codebases.
* **System Architecture**: Designing modular, highly available, and scalable backend services.
* **Performance & Security**: Optimizing query execution, resource utilization, and API security posture.
* **Continuous Growth**: Deepening technical competence across cloud systems, software engineering patterns, and low-level mechanics.
